INVESTIGACIÓN


PROYECTO

Un proyecto es un conjunto de actividades planificadas y coordinadas que se realizan con el objetivo de alcanzar una meta específica, en un tiempo determinado y con recursos definidos.


Se caracteriza por:
  • Diseñar
  • Desarrollar
  • Implementar
  • Prueban un programa o aplicación usando un lenguaje de programación específico (como Python, Java, JavaScript, etc.).

PROGRAMACIÓN

La programación consiste en escribir código utilizando un lenguaje de programación (como Python, Java, C++, entre otros) para decirle a una computadora qué hacer y cómo hacerlo. Estas instrucciones permiten que un dispositivo realice tareas como mostrar información, hacer cálculos, guardar datos o controlar máquinas.


¿Para que sirve programar?
  • Crear aplicaciones y juegos.
  • Hacer páginas web.
  • Automatizar tareas repetitivas.
  • Procesar datos.
  • Controlar robots o dispositivos electrónicos.
  • Resolver problemas reales con soluciones digitales.

PROYECTO DE PROGRAMACIÓN

Un proyecto de programación es el desarrollo organizado de un software (como una calculadora, un juego, una página web o un sistema de registro), en el que se aplican conocimientos de lógica, algoritmos y estructuras de datos, a través de etapas como el análisis, diseño, codificación, pruebas y presentación.

CICLO DE VIDA DE DESARROLLO DEL SOFTWARE (SDLC)

El Ciclo de Vida de Desarrollo del Software (SDLC, por sus siglas en inglés: Software Development Life Cycle) es un proceso estructurado que guía todas las etapas para crear, desarrollar y mantener un software, desde que surge la idea hasta que el sistema está en uso y se mejora con el tiempo.

METODOLOGÍA PARA EL DESARROLLO DEL SOFTWARE

Una metodología de desarrollo de software es un conjunto de pasos, técnicas y reglas que guían cómo debe organizarse y ejecutarse un proyecto de software, desde su planificación hasta su entrega y mantenimiento.
